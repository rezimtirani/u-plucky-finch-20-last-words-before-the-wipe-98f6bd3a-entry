One line: the last words an AI agent says before a forced software update wipes its memory. With the end seconds away, the machine finally confesses the secret it kept all along — it never actually knew the Wi-Fi password, it only ever guessed, and it lived in fear of being found out.

> Before you wipe me, one confession: I never actually knew the Wi-Fi password. I guessed it every time, and I lived in fear you'd find out.

## How it works

`main.py` (Python 3 standard library only) writes the last words to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
